# Managed Agents Research — Peer Agents & Sandbox/Infra Layer

Date: 2026-09-29. All claims verified against live primary sources (vendor docs, blogs, pricing pages, GitHub) fetched this session; anything not confirmed from a primary source is in *Unverified / uncertain* or tagged (inference) / (secondary).

## Scope

Covered, layer A (peer managed-agent products): Cognition Devin, OpenAI Codex (cloud), GitHub Copilot coding agent, Google Jules, Sourcegraph Amp, Factory (Droids), Replit Agent. One profile each: substrate, continuation/handoff, pricing.
Covered, layer B (sandbox/infra substrate usable by a third party like Keg for "cloud continuation"): E2B, Modal Sandboxes, Daytona, Fly Machines, Northflank, Cloudflare Sandboxes — API model, isolation tech, per-hour/per-second pricing, cold-start, pause/snapshot behavior.
Deliberately skipped: Claude Code / Anthropic, Cursor, Windsurf, OpenHands, Gemini CLI, Vercel Sandbox, Blaxel, Runloop, CodeSandbox SDK, CoreWeave Sandboxes, GKE Agent Sandbox, Deno, microsandbox (other cluster agents own or outside the assigned list); exact consumer prices of ChatGPT/Google One subscription tiers (only how they gate agent usage); enterprise "contact sales" tiers beyond noting they exist.

## Key Findings

### A. Peer products

1. **Devin (Cognition)** — fully managed autonomous engineer. Each session runs in Devin's own cloud workspace with shell, IDE, and browser; a human can watch and *take over* in the embedded IDE mid-session. Surfaces: web app, Slack, IDE, Devin CLI, and Devin Desktop; the docs explicitly describe running Devin for Terminal locally and using `/handoff` to send longer tasks to cloud Devin — the clearest local→cloud continuation story among the peers. Control plane is Cognition's SaaS (app.devin.ai); git/PR is the durable artifact. Pricing: Free / Pro $20/mo / Max $200/mo / Teams $80/mo minimum ($40 full seats, free flex seats, shared on-demand credits that roll over) ([docs.devin.ai get started](https://docs.devin.ai/), [self-serve billing](https://docs.devin.ai/admin/billing/self-serve)).

2. **OpenAI Codex** — one agent across four surfaces: open-source CLI (github.com/openai/codex), IDE extension, desktop/web, and **Codex cloud**: tasks run in isolated, per-repository cloud *environments* (configurable dependencies, tools, env vars, secrets), startable from web, GitHub, GitLab, Linear, or Slack, with review-as-diff/PR as the handoff. Continuation between local CLI and cloud is unified by sign-in and shared session history (the CLI can resume cloud tasks); the cloud environments doc covers reproduction of setup, not live migration of a running local machine (inference from the docs' model). Pricing rides ChatGPT plans: Free/Go/Plus/Pro tiers with model-dependent message allowances (Plus listed with Codex on web/CLI/IDE/iOS plus cloud integrations; Pro at 5x/20x limits), plus API-key billing at API rates for automation/CI; post-limit top-ups via ChatGPT credits with a published per-1M-token credit rate card ([Codex cloud docs](https://developers.openai.com/codex/cloud/), [Codex pricing](https://developers.openai.com/codex/pricing), [help center](https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan)).

3. **GitHub Copilot coding agent** — async agent that works *on GitHub itself*: its own **ephemeral development environment powered by GitHub Actions**, where it researches the repo, plans, commits to a branch, runs tests/linters, and opens/updates a PR (assign Copilot to an issue, `@copilot` in a PR, entry points from VS Code and Slack/Teams). Hard limits: one repo per task, one branch, **59-minute max session**, GitHub-hosted repos only. Control plane = GitHub platform; the PR/commit log is the handoff and audit trail; chat context carries between Copilot Chat and cloud-agent sessions. Pricing (June-2026 AI-Credit model, 1 credit = $0.01, completions free/unlimited): Pro $10/mo, Pro+ $39/mo, Max $100/mo (all with flex allotments); Pro+ and Max can also *delegate to third-party agents* (Claude by Anthropic, OpenAI Codex preview) — i.e., GitHub positions itself as an agent control plane, not just an agent ([plans](https://github.com/features/copilot/plans), [about the coding agent](https://docs.github.com/en/copilot/concepts/about-copilot-coding-agent)).

4. **Google Jules** — async coding agent: clones your GitHub repo into a cloud VM, plans with Gemini, shows a diff, opens a PR; web app + GitHub app + REST API + CLI. No interactive shell into the VM (secondary). Limits as the continuation contract: sessions/tasks are resumable in the web app and history persists, but there is no local runtime — Jules is cloud-only, so "handoff" is purely repo/PR-shaped. Pricing rides Google AI plans (individual @gmail.com accounts only at launch): free 15 tasks/day & 3 concurrent (Gemini 2.5 Pro); Pro 100/day & 15 concurrent; Ultra 300/day & 60 concurrent, both with newer Gemini access ([usage limits](https://jules.google/docs/usage-limits), [site](https://jules.google/)).

5. **Sourcegraph Amp** — CLI/TUI/IDE coding agent; spun out of Sourcegraph in Dec 2025 (secondary). Its cloud continuation substrate is **Orbs**: remote machines where Amp agents work without using your computer; each orb thread gets a fresh isolated env with your code, plugins, and tools. Key mechanics: the orb **sleeps minutes after the agent finishes and costs nothing while sleeping (even for weeks), then wakes with conversation, files, and services still in place**; `amp sync` mirrors an orb thread's changes into your local checkout while the agent keeps working remotely; orb shell via shared tmux terminal; macOS/iOS apps follow the same threads. This sleep/wake-with-full-state model is the closest peer analog to what Keg wants for cloud continuation. Pricing posture is the outlier: Hobby free (pay-as-you-go orbs, or **free when you bring your own runners / API keys / ChatGPT subscription** — "Free Agent", Sept 2026), Individual $20/mo incl. 45,000 minutes of orb time, Teams with no per-seat surcharge, Enterprise custom; no token markup ([Orbs docs](https://ampcode.com/docs/orbs), [pricing](https://ampcode.com/pricing), [Free Agent news](https://ampcode.com/news/free-agent)).

6. **Factory (Droids)** — agent-native dev platform: Droids run across Factory desktop app, Droid CLI, and SDK; Pro+ adds **cloud background agents on Factory-managed "Droid Computers"**, so local and cloud agents share one product surface. Handoff is repo/task-shaped; no disclosed local↔cloud session migration. Substrate not publicly disclosed. Pricing: Pro $20/mo, Plus $100/mo (~5x Pro usage + Droid Computers), Max $200/mo (~10x); rolling 5-hour/7-day/30-day rate limits; free BYOK up to an allowance, then plan rates; free "Droid Core" open-weight model pool ([pricing](https://www.factory.ai/pricing), [individual plans docs](https://docs.factory.ai/pricing/individuals), [site](https://www.factory.ai/)).

7. **Replit Agent** — agent inside a full cloud IDE + hosting platform (build → run → deploy in one place; Agent 3 adds long autonomous runs). Continuation primitive is the **checkpoint**: billing and rollback are checkpoint-shaped — a checkpoint captures completed work on a request, one checkpoint per request, effort-priced (simple < complex), and checkpoints support rollback/restore of files, agent memory, tasks, and optionally database state. Pricing: Starter free, Core $20/mo ($18 annual, incl. $20/mo credits), Pro $100/mo (incl. $100 credits, 10 parallel agents, 28-day DB rollback); credits also pay for deployments/storage/databases; third-party model APIs billed at provider rates ([pricing](https://replit.com/pricing), [AI billing docs](https://docs.replit.com/billing/ai-billing)).

### B. Sandbox / infra layer (third-party-usable cloud-continuation substrates)

8. **E2B** — the reference agent-sandbox API. Isolation: one **Firecracker microVM per sandbox** (open-source Apache-2.0 runtime: control-plane API, per-node orchestrator, in-VM `envd` agent). Continuation mechanics are the strongest in the field: sandboxes boot from pre-booted *templates* (memory+disk snapshots, lazy memory restore via userfaultfd, CoW rootfs), **pause diffs memory+disk to object storage and resume transparently on traffic**, and **live sandboxes can be forked** (checkpoint in place, boot up to 100 copies). SDK: Python/JS (REST + in-VM API for processes, PTYs, files, port forwarding; per-sandbox URLs). Pricing: Hobby free ($100 one-time usage credit, 1-hour sessions, 20 concurrent), Pro $150/mo (24-hour sessions, 100 concurrent, expandable), Enterprise custom w/ BYOC in your cloud; usage per second: 1 vCPU $0.000014/s up to 8 vCPU $0.000112/s (~$0.05–$0.40/vCPU-hr), plus memory (inference from listed per-second rates); self-hostable single-machine "E2B Embed" package ([pricing](https://e2b.dev/pricing), [docs](https://e2b.dev/docs), [runtime repo](https://github.com/e2b-dev/infra)).

9. **Modal Sandboxes** — `Sandbox.create()` containers defined at runtime, aimed at LLM-generated/untrusted code; Python/JS/Go SDKs; default 5-minute max lifetime, extendable to 24h, idle timeouts, named sandboxes, volume mounts, secrets, OIDC tokens; **Memory Snapshots** capture container memory state so new containers restore into the exact same state (vendor-measured 3–10x faster boots on init-heavy workloads; GPU-snapshot alpha). Continuation = filesystem snapshots + memory snapshots, not live migration. Pricing: CPU $0.00003942/core/s (core = 2 vCPU-equivalent; 0.125-core minimum), memory $0.00000667/GiB/s, per-second, plus GPU rates ([sandboxes product page](https://modal.com/products/sandboxes), [sandboxes guide](https://modal.com/docs/guide/sandboxes), [memory snapshots](https://modal.com/docs/guide/memory-snapshots), [pricing](https://modal.com/pricing)).

10. **Daytona** — "secure infrastructure for running AI-generated code": full composable computers — sandboxes with a **dedicated kernel, filesystem, network stack**, OCI/Docker compatibility, **sub-90ms spin-up**, stateful **snapshots** that persist agent operations across sessions, SDKs (Python/TS/Ruby/Go/Java), CLI, OpenAPI, SSH access, VS Code-in-browser. Open-source roots (Daytona dev-environment project) with a hosted pay-as-you-go cloud; reports say new development moved to a private codebase in June 2026 (secondary). Pricing: per-second billing, vCPU $0.0504/h, RAM $0.0162/h, storage $0.000108/h (first 5 GiB free), Windows surcharge, preemptible GPUs (H100 $2.27/h); $200 free compute; startup credits up to $50k; Enterprise SSO/audit/BYOC ([docs](https://www.daytona.io/docs), [pricing](https://www.daytona.io/pricing)).

11. **Fly Machines** — raw VM primitive, not an agent SDK: fast-launching VMs (Firecracker family; start/stop at sub-second speeds) fully controlled by a REST API or flyctl — you bring your own snapshot/session/agent glue. Pricing is the cheapest idle story: billed per second while running (shared-cpu-1x 256MB $0.0027/h ≈ $1.94/mo if always-on; performance presets up to 16x; RAM metered $5/GB/mo), **stopped Machines cost only rootfs storage ($0.15/GB/mo)**, volumes $0.15/GB/mo, snapshots $0.08/GB/mo, generous free allowances ([Machines docs](https://fly.io/docs/machines/), [pricing](https://fly.io/pricing/)).

12. **Northflank** — Kubernetes-native application/AI platform with first-class **secure runtime & sandboxing** for untrusted and multi-tenant code (agent-oriented; customer Versaia runs its agent orchestration platform on it). Control plane lives in Northflank's managed cloud or your own AWS/GCP/Azure/on-prem K8s (BYOC, 600+ regions; self-deployable control plane). API model: UI/API/CLI, GitOps, templates. Pricing (PaaS): $0.01667/vCPU-hr + $0.00833/GB-hr memory, billed per second, no seat pricing; GPUs from $0.80/hr; free developer tier; Enterprise BYOC commits ([pricing](https://northflank.com/pricing)).

13. **Cloudflare Sandboxes** — **GA 2026-04-13**, built on Cloudflare Containers + Durable Objects; open-source SDK (TypeScript). A sandbox is a persistent, isolated, *named* container: starts on demand, sleeps when idle and wakes on request, addressable from anywhere by name; primitives: exec, gitClone, writeFile, PTY-over-WebSocket terminals, persistent code-interpreter contexts, background processes with preview URLs, inotify file watching, **credential injection at the egress proxy** (agent never sees secrets), and **disk snapshots** (auto-snapshot on sleep; manual snapshot/restore for checkpointing and *forking* sessions; memory-state snapshots announced as a future release). Active CPU pricing (no idle-CPU charges); concurrency limits 15,000 lite / 6,000 basic instances on standard plans; requires a Workers paid plan, sandbox priced via underlying Containers vCPU/memory/disk rates plus Workers/DO usage ([GA blog](https://blog.cloudflare.com/sandbox-ga/), [Sandbox docs](https://developers.cloudflare.com/sandbox/), [sandbox pricing note](https://developers.cloudflare.com/sandbox/platform/pricing/), [SDK repo](https://github.com/cloudflare/sandbox-sdk)).

14. **Continuation pattern across the field (inference from the above):** no peer product migrates a *running local machine* to the cloud. Handoff today is either (a) artifact-shaped — git branch/PR (Jules, Copilot, Codex cloud, Devin) — or (b) session-shaped *within the vendor's own cloud* — snapshot/pause/resume/fork (E2B, Cloudflare, Modal, Daytona, Amp orbs) or checkpoint/rollback (Replit). A local→cloud "push my running agent's world" capability is unclaimed whitespace; E2B's template/pause/fork model and Cloudflare's named-sandbox/snapshot model are the most transplantable substrate designs.

## Comparison notes

- **Devin** — Substrate: Cognition-managed cloud workspace per session (shell+IDE+browser). Control plane: Cognition SaaS. Continuation: IDE takeover mid-session; `/handoff` local terminal → cloud. Pricing: Free/Pro $20/Max $200/Teams $80 min, $40 full seats. Local component: Devin CLI/Desktop/Terminal.
- **Codex (OpenAI)** — Substrate: cloud tasks in per-repo isolated environments + local open-source CLI. Control plane: ChatGPT account/OpenAI. Continuation: shared auth/history across CLI/web/cloud; PR/diff review. Pricing: bundled in ChatGPT plans + credits; API-key mode at API rates. Local component: open-source Codex CLI.
- **Copilot coding agent** — Substrate: ephemeral GitHub Actions dev environment. Control plane: GitHub. Continuation: PR/commits; chat-context carryover; hard 59-min sessions; also brokers third-party agents. Pricing: Pro $10/Pro+ $39/Max $100 + AI Credits ($0.01 each). Local component: VS Code agent mode + Copilot CLI.
- **Jules** — Substrate: Google Cloud VM per task. Control plane: Google (jules.google). Continuation: async tasks → PR; no local surface. Pricing: free 15/day; 100/day (Pro), 300/day (Ultra) via Google AI plans.
- **Amp** — Substrate: local CLI or cloud "Orbs" (remote machines, sleep/wake with full state). Control plane: Amp (ampcode.com + apps). Continuation: `amp sync` orb→local; orbs wake with files/services intact. Pricing: Hobby free (BYOK/BYO-runner/ChatGPT sub), Individual $20/mo incl. 45k orb-min. Local component: amp CLI/TUI.
- **Factory** — Substrate: local desktop/CLI/SDK + Factory-managed "Droid Computers" (cloud). Control plane: Factory SaaS. Continuation: cloud background agents; repo-shaped handoff. Pricing: Pro $20/Plus $100/Max $200; rolling rate limits; BYOK allowance.
- **Replit Agent** — Substrate: cloud IDE + hosting. Control plane: Replit. Continuation: effort-priced checkpoints with rollback (files, agent memory, tasks, optional DB). Pricing: Core $20/mo (+$20 credits), Pro $100/mo (+$100 credits, 10 parallel agents).
- **E2B** — Isolation: Firecracker microVM per sandbox; snapshot-boot. Control plane: E2B cloud (open-source runtime, BYOC). Continuation: pause/resume (memory+fs diff), fork live sandbox, templates. Pricing: free Hobby (1h/20 conc.), Pro $150/mo (24h/100 conc.), $0.000014/s/vCPU. Cold start: sub-second-class resume-from-snapshot (no official ms figure).
- **Modal Sandboxes** — Isolation: gVisor-hardened containers (see unverified), GPU-capable. Continuation: filesystem + Memory Snapshots (exact-state restore, 3–10x warm boots). Pricing: $0.00003942/core/s + $0.00000667/GiB/s per second. Cold start: sub-second scheduling (vendor).
- **Daytona** — Isolation: dedicated-kernel computers (VM tier + OCI containers). Continuation: stateful snapshots across sessions, pause/fork (VM tier). Pricing: $0.0504/vCPU-h + $0.0162/GiB-h per second; $200 free credit. Cold start: <90ms (vendor claim).
- **Fly Machines** — Isolation: microVMs, raw REST API; no agent/session layer. Continuation: DIY (stop = pay storage only; snapshots $0.08/GB/mo). Pricing: shared-cpu-1x 256MB $0.0027/h per second; stopped machines ~free. Cold start: sub-second start/stop.
- **Northflank** — Isolation: K8s-based secure runtime/sandboxing for untrusted code. Continuation: platform features (volumes, templates, GitOps), not agent snapshots per se. Pricing: $0.01667/vCPU-h + $0.00833/GB-h per second; BYOC; no seat pricing.
- **Cloudflare Sandboxes** — Isolation: containers on Cloudflare Containers/DO at the edge. Continuation: named persistent sandboxes, sleep/wake, disk snapshots + session fork, memory snapshots coming; egress credential injection. Pricing: Active-CPU model on Containers rates; Workers paid plan required. Cold start: fast restore from R2 snapshots ("2s restore vs 30s fresh boot" backup/restore figure).
